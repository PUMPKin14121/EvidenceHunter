\# Contributing to EvidenceHunter



Thank you for your interest in EvidenceHunter.



\## Development Principles



Contributions should follow these principles:



\- Evidence before conclusions

\- Clear documentation of changes

\- Reproducible experiments

\- Respect for existing architecture



\## Pull Requests



Before submitting a pull request:



1\. Explain the purpose of the change

2\. Describe implementation details

3\. Include testing information

4\. Update documentation when necessary



\## AI-Assisted Contributions



AI tools may be used during development.



However, contributors are responsible for:



\- reviewing generated code

\- validating behavior

\- maintaining project quality
