# EvidenceHunter

## An AI-Assisted Research Framework for Evidence-Based Market Observation

EvidenceHunter is a research-grade software framework exploring how modern AI coding agents can assist in building and maintaining complex research systems.

This project started as an experiment:

> Can a person without a traditional programming background use AI coding agents to independently design, implement, test, and maintain a sophisticated software system?

The goal is not to create a guaranteed-profit trading system.

EvidenceHunter focuses on:

- market observation
- evidence collection
- outcome reconstruction
- hypothesis evaluation
- research governance


## What EvidenceHunter Is

EvidenceHunter is an evidence-based opportunity ranking framework.

It is designed to:

- collect structured market observations
- evaluate hypotheses against historical evidence
- separate observations from conclusions
- prevent premature claims


## What EvidenceHunter Is Not

EvidenceHunter is NOT:

- a price prediction system
- financial advice
- a guaranteed trading strategy
- an autonomous trading bot


## AI-Assisted Development

This project was developed with AI coding agents.

The development process emphasizes:

- AI output is untrusted by default
- evidence before claims
- tests before conclusions
- versioned changes
- controlled iteration


## Research Philosophy

Evidence before belief.

A hypothesis must be:

1. Defined
2. Tested
3. Validated
4. Reproduced

A single successful result is not considered sufficient evidence.


## Status

This project is currently a research and engineering experiment.

The goal is to explore responsible AI-assisted software development.
